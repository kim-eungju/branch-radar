            판정 기준 안내
            
    
                
  • 뒤처짐: 전체 브랜치 중 가장 높은 Flyway 버전 파일이 없음. 이전 버전을 유지하는 release 브랜치일 수 있으며, 배포 오류가 확정된 것은 아닙니다.
    • 
                
  • 충돌 위험: 같은 버전에 다른 파일명/SQL 이 존재하거나, 한 브랜치 안에 같은 버전이 둘 이상 있음(Flyway 실행 시 실제 오류).
                    기준 브랜치에 있는 버전은 기준 브랜치의 파일을 정답으로 보고, 그와 다른 브랜치만 충돌로 표시합니다.
    • 
                
  • SQL 내용 비교는 Git blob SHA 로 하며, Flyway checksum(CRC32)과는 다른 값입니다.
    • 
                
  • 활동 상태는 마지막 커밋 날짜(일 / 일 기준)이며, 브랜치 생성일이 아닙니다.
